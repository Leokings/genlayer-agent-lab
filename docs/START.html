START WITH THE AGENT YOU ALREADY USE

One setup prompt.
Your agent handles the installation.

Give the prompt to OpenClaw or a coding agent with terminal access to your computer or VPS. It checks what is needed, installs missing software and prepares your Lab.

Get your Lab ready

  1. Open an agent that can run commands on your chosen machine.
  2. Paste the setup prompt. Follow any password or system confirmation it needs.
  3. Open your dashboard, review a test and connect the agent you want to test.

Read or copy the full prompt

Your agent keeps its current model. The first Studio download and build can take tens of minutes; the prompt asks it to leave that work running so you can return later.

Do I need to install Docker first?

No. The agent checks for Docker and the other prerequisites, reuses what you have and installs what is missing on supported systems. It may need you to enter an administrator password, approve an operating-system dialog, or sign in again before continuing.

Where can I run it?

The automated prerequisite helper supports Ubuntu 22.04 and 24.04 on an x86-64 VPS or computer. On Windows x86-64 and Intel Macs, your agent follows the Docker Desktop setup steps and helps with required system actions. The current Studio environment requires Linux x86-64 containers; an Apple Silicon or other ARM machine needs access to a supported x86-64 host.

What if my agent is on a different machine?

It needs terminal or SSH access to the computer that will run the Lab. An agent running on a VPS cannot change Termius on your laptop; it will give you the forwarding settings for that step. A chat-only assistant needs a tool-enabled host before it can install software.

Does installation start an agent test?

Installation prepares the environment and can run a scripted installation check. You then review a test in the dashboard. Its separate connection prompt contains the settings for the agent you want to evaluate. A passing installation check does not mean that agent passed.

GenLayer Agent Lab runs in your own environment. Setup preserves existing installations and saved tests. See your first test walkthrough.
