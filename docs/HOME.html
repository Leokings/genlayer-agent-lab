Tools & practical details

What powers
the Lab?

How does the Lab use GenLayer Studio?

GenLayer Studio is the local execution environment beneath Studio mode. The Lab starts its own Studio environment, runs supported project contracts, and records the agent’s operations and their results. Tests can observe the local transaction lifecycle, finality, permitted protocol appeals and supported fee accounting. Possible contract model responses are supplied by the test author.

The Lab adds reviewed agent scenarios, scoped tools, action recording and behavioral checks around Studio. Developers can also build their own agent test harness around Studio.

How does the Lab use GLSim?

Quick mode uses GLSim to execute supported contract evaluations with controlled inputs. The Lab controls the timing of decisions the agent sees and simulates application effects. This scripted timeline lets you test how the agent responds to the available situations; its statuses are not observed GenLayer finality. Quick mode has no protocol appeals and uses a separate scenario format from Studio.

How does my agent connect?

The Lab gives each run its own tools and permissions. An agent can use the local MCP bridge, which connects agents to tools, or call the HTTP interface from code; Python and TypeScript examples show how. The generated connection prompt provides the selected mode’s settings. Your agent keeps its model and reasoning, but its relevant test actions must use the Lab’s interface.

A remote or managed agent needs a reachable route to the Lab and a supported tool connection. An agent with hardcoded wallet or RPC calls may need its developer to adapt those calls.

Which computers are supported?

The current Studio environment requires Linux x64 containers. Use a Linux x64 host, Windows x64 with Docker Desktop, or an Intel Mac with Docker Desktop. The automated Linux prerequisite helper supports Ubuntu 22.04 and 24.04. Apple Silicon and other ARM devices currently need access to a supported x64 host, such as a VPS. Check host requirements.

What does a passing report tell me?

It shows that the recorded agent behavior met the reviewed expectations for that run in its stated environment. The developer supplies possible contract model responses and grading rules. A pass does not measure the contract model’s judgment accuracy, certify the agent or establish public-network settlement behavior.

Does a scripted check count as testing my agent?

No. Included reference agents can check the installation and exercise a scenario with scripted behavior. To evaluate your own agent, connect it to a fresh run, confirm that it actually uses the Lab’s interface, and inspect that run’s report.
